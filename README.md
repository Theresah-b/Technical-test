# Shopify Technical Test

## Overview

This project is a responsive implementation of the provided Figma design as part of a Shopify technical assessment.

## Technologies Used

* HTML5
* CSS3

## Features

* Responsive layout
* Implementation of the provided Figma design
* Clean and maintainable code structure
* Image assets

## Project Files

* `index.html` – Main page structure
* `style.css` – Styling and layout
* `images/` – Project assets and images

## Design Approach

The page was developed using semantic HTML and modern CSS techniques, including Flexbox and CSS Grid. Typography, spacing, colors, and visual elements were implemented to match the provided Figma design while ensuring responsiveness across different screen sizes.

## Running the Project

1. Download or clone the repository.
2. Open the project folder.
3. Launch `index.html` in a web browser.
